Card Pull Rates — About / FAQ

Using the controls

Search filters cards by name. The Tiers / Collections / Type / Tags dropdowns are multi-selects (Tags mirrors the tag filter on osrs-tcg.net): click options to toggle them (each shows how many cards match). Clicking a card's tier chip in the table also filters to that tier. Filters and search are remembered between visits; Reset filters clears everything.

Sorting: click a column header to sort by it, click again to flip the direction (▲/▼). Shift-click another column to sort by that column as well — the small numbers next to the arrows show the sort order (¹ = primary, ² = secondary, and so on). Shift-clicking an already-sorted column flips its direction. A plain click on any header resets back to a single-column sort. Your sort config is remembered between visits.

Hover a card's art for about a second to see a larger preview.

Where the data comes from

All stats are based on publicly available data from the osrs-tcg.net public API (card catalog + circulation figures). Only overall values per card are published — pulls and copies-in-existence are not broken down per collection, so this site cannot show per-collection stats. Collections are listed per card, but the stats themselves are global.

How accurate are the numbers?

The stats are a reflection of the publicly available live data, which may differ from the actual server-side values (the API can serve cached snapshots, and we only see what it exposes). All we have is that public reflection. That said, by the law of large numbers the relative stats — pull rate %, 1-in-X — should become more accurate over time as the total number of recorded pulls grows.

How the odds are calculated

Pull rate % = this card's total pulls (normal + foil) ÷ all card pulls, as a percentage. 1 in X = total pulls across all cards ÷ this card's pulls — i.e. on average, roughly 1 in X pulls yields this card. These are observed frequencies from the public data, not official pack odds (which aren't published).

Average foil rate across all recorded pulls: … (assumed ~1% — official foil odds aren't published, so this observed frequency is our best estimate).

Exist = copies currently in circulation (supply). Pulled − exist compares interest vs supply: positive means the card has been pulled more often than copies currently exist (relatively scarce); negative means more copies exist than pulls, presumably due to beta collection imports.

How this site is hosted

An automated hourly job on a home server fetches the public API, rebuilds the dataset, and publishes everything as a static site to GitHub Pages. Nothing runs server-side when you browse, and no data about you is collected.

A note on accuracy

This app is roughly 95% vibe coded, so mistakes are entirely possible. Double-check anything important against osrs-tcg.net.
