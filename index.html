Card Pull Rates - About / FAQ

How to use this site

Search filters by card name; the Tier / Collection / Type / Tags dropdowns are multi-selects (Tags mirrors osrs-tcg.net) with per-option match counts. Clicking a tier chip in the table filters to that tier. Filters, sorting, and search persist between visits; Reset filters clears everything.

Sorting: click a header to sort, click again to flip direction. Shift-click adds a secondary sort - small numbers mark the order (¹ primary, ² secondary). Shift-clicking a sorted column flips it; a plain click resets to a single-column sort.

Hover a card's icon for half a second to see a larger preview, sized to the artwork itself.

Cards with a known full-art version carry a gold Has full art tag next to the type tag - hover it for half a second to preview the full art. The Full art only button shows just those cards. The set changes as new full-art cards get pulled or added.

Where the data comes from

All stats come from the osrs-tcg.net public API (card catalog + circulation). Only per-card totals are published - nothing is broken down per collection, so per-collection stats aren't possible; the stats themselves are global.

Where the headline numbers come from

Packs opened is the official pack counter; total card pulls is packs × 5 - exactly how osrs-tcg.net computes its own figure (verified in their site code), so our headline matches theirs. Snapshots refresh minutes apart and rebuilds are hourly, so expect sub-1% wobble. Beta cards are excluded throughout: official docs say player stats omit them and imports don't count toward collection statistics.

Footnote: on the morning of Sep 5 (UTC) the official per-card totals jumped ~30% in a bulk backfill (~1.3× across nearly all cards) - older snapshots read much lower.

How the odds are calculated

Pull rate % = this card's total pulls (normal + foil) ÷ all card pulls, as a percentage. 1 in X = total pulls across all cards ÷ this card's pulls - i.e. on average, roughly 1 in X pulls yields this card. These are observed frequencies from the public data, not official pack odds (which aren't published).

Each pack holds 5 cards; a foil takes one slot. The foil rate is … of tracked pulls, bounded by … (removed cards were almost never foils) - computed live every time the site is updated. The community's long-standing 1% assumption checks out.

Exist = copies currently owned. Pulled − exist = tracked pulls no longer owned (currently …), almost all normals - sold, consumed, or removed (only a few hundred tracked foils are missing). Negative means more owned than pulled: a few cards were granted outside packs or remapped (e.g. Hoop snake, Crawling Hand).

How this site is hosted

An automated hourly job on a home server fetches data from public API, rebuilds the dataset, and publishes everything as a static site to GitHub Pages. Nothing runs server-side when you browse, and no data about you is collected.

A note on accuracy

This app is roughly 95% vibe coded, so mistakes are entirely possible. Double-check anything important against osrs-tcg.net.
